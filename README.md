# TechReq

TechReq — консольное приложение для управления заявками в техническую поддержку. Проект предназначен для автоматизации основных процессов работы службы технической поддержки. Приложение позволяет регистрировать пользователей, выполнять авторизацию, создавать и просматривать заявки, а также предоставляет сотрудникам технической поддержки возможность обрабатывать заявки, изменять их статус, отвечать пользователям.

## Возможности

В проекте реализованы следующие основные возможности:
* создание заявки в техническую поддержку
* просмотр заявок 
* обработка заявки сотрудником
* ответ на заявку
* изменение статуса заявки
* закрытие заявки
* просмотр истории заявок
* регистрация пользователя
* вход пользователя или сотрудника в систему

## Архитектура

Приложение построено с использованием многослойной архитектуры.

```text
Пользователь
     │
     ▼
Консольный интерфейс
(main.py, menu.py, auth.py)
     │
     ▼
Сервисный слой
(services)
     │
     ▼
Слой доступа к данным
(repositories)
     │
     ▼
База данных
(database)
```

Такое разделение позволяет отделить пользовательский интерфейс от бизнес-логики и операций с данными.

### Основные компоненты

#### `main.py`

Точка входа в приложение. Выполняет инициализацию необходимых компонентов и запускает программу.

#### `menu.py`

Содержит логику взаимодействия с пользователем через консольное меню.

#### `auth.py`

Отвечает за регистрацию и авторизацию пользователей.

#### `models`

Содержит модели основных сущностей предметной области, включая пользователей, книги, авторов и бронирования.

#### `repositories`

Содержит компоненты, отвечающие за получение, добавление, изменение и удаление данных.

#### `services`

Содержит бизнес-логику приложения и обеспечивает взаимодействие между пользовательским интерфейсом и слоем доступа к данным.

#### `database`

Содержит компоненты, необходимые для работы с базой данных и её инициализации.

## Требования

Для запуска проекта необходимо установить:

* Python 3.14 или выше;
* Git.

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd LibTrack
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Windows Command Prompt:

```cmd
.venv\Scripts\activate.bat
```

Linux и macOS:

```bash
source .venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск приложения

Из корневой папки проекта выполните:

```bash
python -m src.libtrack.main
```

После запуска в консоли будет отображено главное меню приложения.

```text
===== Техническая поддержка =====
1. Вход
2. Регистрация пользователя
0. Выход
```

Пользователь может выбрать необходимое действие, введя соответствующий номер.

## Работа в Visual Studio Code

Для запуска проекта в Visual Studio Code необходимо выбрать интерпретатор Python из виртуального окружения:

```text
.venv\Scripts\python.exe
```

Конфигурация запуска находится в файле:

```text
.vscode/launch.json
```

Проект запускается как Python-модуль:

```text
src.techreq.main
```

Это позволяет корректно использовать пакетную структуру проекта и абсолютные импорты.

## Разработка

Исходный код проекта располагается в каталоге:

```text
src/techreq/
```

При разработке рекомендуется соблюдать следующую организацию кода:

* модели предметной области размещать в `models`;
* работу с базой данных размещать в `repositories`;
* бизнес-логику размещать в `services`;
* код пользовательского интерфейса размещать отдельно от бизнес-логики.
